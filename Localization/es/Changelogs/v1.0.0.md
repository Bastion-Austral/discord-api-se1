[h3][1.0.0] - 2026-08-19[/h3]

[h2]Añadido[/h2]
[list]
[*] [b]Lanzamiento Inicial[/b]: Versión completa de la utilidad Discord API para Space Engineers.
[*] [b]Seguimiento de Eventos[/b]: Captura conexiones y desconexiones de jugadores, mensajes de chat público y muertes de personajes.
[*] [b]Cola basada en Archivos[/b]: Utiliza registros en disco para evitar caídas de rendimiento en el hilo del juego.
[*] [b]Aplicación de Relé Externo[/b]: Implementación de una aplicación DiscordRelay auto-contenida en un solo ejecutable para Windows.
[*] [b]Límites de Tráfico (Rate Limiting)[/b]: Sistema de cola dinámica en el relé para evitar penalizaciones de la API de Discord.
[*] [b]Enrutamiento Personalizado[/b]: Soporte para enviar alertas de chat, registros y conexiones a diferentes canales de Discord.
[*] [b]Aviso de Exclusión y Firmas[/b]: Se agregaron firmas criptográficas SHA-256 y scripts de compilación automática.
[/list]

[h1]Discord API - CHANGELOG v1.0.0[/h1]

[h3][1.0.0] - 2026-08-19[/h3]

[h2]Added[/h2]
[list]
[*] [b]Initial Release[/b]: Full Discord API companion mod release for Space Engineers.
[*] [b]Event Tracking[/b]: Hooks player connections, disconnections, public chat messages, and player deaths.
[*] [b]File-based Queuing[/b]: Relies on disk storage logs to prevent network-thread performance locks.
[*] [b]External Relay Application[/b]: Implemented a self-contained single-file DiscordRelay application for Windows.
[*] [b]Discord Rate Limiting[/b]: Dynamic payload queuing on the relay to prevent Discord API rate limit penalties.
[*] [b]Custom Routing[/b]: Support for routing chat, logs, and connection alerts to different Discord channel Webhooks.
[*] [b]Security Disclaimers & Signatures[/b]: Added SHA-256 hash checks and compilation scripts.
[/list]
